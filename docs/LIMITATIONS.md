# 范围与已知限制

- 只支持 Windows x64 的已验证构建。
- 仅完成主菜单、子菜单和部分标题栏按钮、提示；不是全界面汉化。
- 中文在编译时固定，未添加 `ui_locale` 或其他语言切换设置。
- 快捷键、动作标识、文件名、分支名和用户内容保留原值。
- 未找到翻译键时显示原文。
- 自动更新关闭，需要维护者发布新版本；补丁只适用于固定的上游提交。
- 此构建使用优化等级 1 并关闭调试符号，性能未与官方构建全面比较。
- 2026-10-09 的窗口截图工具超时，未完成中文菜单的视觉验收。
- WSL 测试日志出现过未处理的 `ExternalAgentsUpdated` 消息；未阻止项目窗口打开，但外部智能体相关功能未验证。
- 未完成所有菜单动作、调试、插件、不同显卡和其他 Windows 配置的全面测试。
- 没有代码签名；下载文件应来自本仓库 Releases 并核对校验和。

请通过 GitHub Issues 附上版本、Windows 版本和复现步骤。分享日志前移除令牌和私人项目内容。
